# Larry Run Club 🐈

A mobile-friendly, static interactive website featuring two photos of Larry the cat. Click Larry to make him run. All image assets are embedded in `public/index.html`.

## Deploy to Render

1. Create a **new GitHub repository** (public or private, accessible to Render).
2. Upload the unzipped files, preserving `public/index.html` and `render.yaml`.
3. In Render, choose **New → Blueprint**, select the repository, review the free static-site configuration, then Apply.
4. Wait for deployment status **Live** and open your new `onrender.com` link.

Alternatively create a Render Static Site pointing to the repository: build command `echo ready`, publish directory `public`.

This project is independent of any other Render services.
